# Native Application Admission Policies

This directory contains kOA admission/data policy for native applications. It does not replace Freedesktop `.desktop`, MIME, icon, or application metadata authority.

`admission/` contains enabled policies for permanent conformance applications. `data/` describes persistence/cache/rollback semantics consumed by existing kOA backup/restore machinery. `fixtures/files-selection.json` intentionally keeps the Files product selection open.
